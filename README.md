# Для самой классной Марины ✨🐰💚

Интерактивный, легкий и искренний сайт-опросник для Марины.

## 🌸 Особенности:
- **Цветовая палитра**: Нежный розовый, чистый белый, лавандовый и фиолетовый с изумрудно-зеленым акцентом для NFT зайчика.
- **Без AI-слоп**: Качественный авторский дизайн, приятная типографика (Comfortaa + Nunito), плавные анимации и живые микро-реакции.
- **Интерактив**:
  - Анимированный прыгающий зайчик на шкале прогресса
  - Веб-аудио эффекты (легкие щелчки и торжественные аккорды синтезатора без внешних файлов)
  - Анимированный NFT зайчик с шевелящимися ушками, моргающими глазками и пульсирующим сердечком
  - Игривая кнопка «Надо подумать...» с забавными уговорами
  - Праздничный салют конфетти при согласии и удобная кнопка копирования ответа для автора
- **Архитектура**:
  - Легковесный чистый Vanilla HTML5 / CSS3 / JavaScript
  - Готовый Dockerfile на базе `nginx:alpine` с настроенным gzip сжатием и безопасными заголовками
  - Полная поддержка мобильных устройств (iOS Safari, Android Chrome, Telegram WebApp)
